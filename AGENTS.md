# Чат (Slack) — учебный проект Hexlet

Упрощённый аналог Slack: каналы, сообщения в реальном времени, регистрация и вход.
Задание: https://ru.hexlet.io/projects/12/members/22522?step=N (шаг «Подготовка» и шаги 1–13). Требования шагов копятся в разделе «Шаги» ниже по мере прохождения.

## Целевой стек (требование проекта)

- Сборка — **Vite**. React с хуками, клиентский роутинг (react-router).
- **Серверное состояние** (каналы, сообщения) — **TanStack Query**: данные не хранятся, а кешируются; загрузка, обновление, индикатор загрузки, обработка ошибок.
- **Клиентское состояние UI** (открытый канал, показанная модалка, текущий пользователь) — **Zustand**: хранилище на хуках, без редьюсеров и экшенов.
- Эти два вида состояния держать раздельно: серверные данные — в Query, UI — в Zustand.
- Формы — **@mantine/form**.
- UI — **Mantine**. Внешний вид задаётся пропсами компонентов и темой; доступность (фокус в модалке, Escape, клавиатура в меню) берётся из компонентов Mantine.
- Свой CSS в проекте не пишется.
- Бэкенд — готовый `@hexlet/chat-server`: REST API и веб-сокеты (socket.io).
- Продакшен: сборка, деплой на Render, мониторинг ошибок (например, Bugsink).
- Эталонная заготовка Hexlet: https://github.com/hexlet-components/js-react-hexlet-chat — сверяться с ней по раскладке и конфигам.

## Интерфейс по демо Hexlet

Демо (скриншоты): https://files.hexlet.app/a/ose685. Тексты интерфейса брать отсюда дословно — по ним ищут элементы проверки.

- **Шапка:** «Hexlet Chat» слева (ссылка на `/`), кнопка «Выйти» справа — только для вошедшего.
- **Вход `/login`:** карточка с картинкой слева; заголовок «Войти», поля «Ваш ник» и «Пароль» (с глазом), кнопка «Войти»; внизу «Нет аккаунта? Регистрация». Клиентской валидации нет; ошибка сервера под паролем — «Неверные имя пользователя или пароль».
- **Регистрация `/signup`:** «Регистрация»; поля «Имя пользователя», «Пароль», «Подтвердите пароль»; кнопка «Зарегистрироваться». Ошибки: «От 3 до 20 символов», «Не менее 6 символов», «Пароли должны совпадать».
- **404:** «Страница не найдена», «Но вы можете перейти на главную страницу» (ссылка на `/`).
- **Чат `/`:** слева «Каналы» и кнопка «+», список `# general`, `# random`; у добавленных каналов — выпадающее меню «Удалить» / «Переименовать». Справа заголовок `# канал`, счётчик «N сообщений», сообщения в виде «**user**: текст», поле «Введите сообщение...» с кнопкой отправки.
- **Модалки:** «Добавить канал» / «Переименовать канал» — поле «Имя канала», кнопки «Отменить» / «Отправить»; «Удалить канал» — «Уверены?», кнопки «Отменить» / «Удалить» (красная).
- **Уведомления** внизу справа, например «Канал создан».

## Решения проекта

- **TypeScript** (свежий, сейчас 7.x), `strict`. Весь код — `.ts`/`.tsx`. Импорты с явным расширением (`./init.tsx`).
- Контракт проверки Хекслета требует `src/init.jsx`: он остаётся реэкспортом из `src/init.tsx`. Тест `__tests__/smoke.test.tsx` импортирует именно `src/init.jsx`.
- Линт и формат — oxlint + oxfmt с конфигами из эталонной заготовки (канон Хекслета). `make lint` = typecheck + oxlint + oxfmt.
- Версии зависимостей — последние на момент установки.
- Тесты — Vitest + Testing Library в `__tests__/`, окружение jsdom, общий setup — `__tests__/setup.ts` (заглушка `matchMedia` для Mantine). Компонент вне `App` рендерить внутри `MantineProvider`. Роутинг проверяется через `window.history.pushState` перед `render(<App />)`.
- `package.json` минимальный: только `name`, `private`, `type` и зависимости, без `scripts`. Все команды — в `Makefile` через `npx`.

## Шаги

Каждый шаг добавляет вводные и усиливает требования; более поздний шаг уточняет более ранний.

- **Подготовка (step=0).** Знакомство с проектом: цель и стек описаны выше. Результат — рабочее окружение готово.
- **Запуск проекта (step=2).**
  - Фронтенд в корне репозитория, бандл — в `dist`. Имя пакета — `@hexlet/code`.
  - `src/init` по умолчанию экспортирует async-функцию: принимает сокет, возвращает разметку, готовую к рендеру. Сокет — параметр (проверки подставляют свой), поэтому провайдеры, роутер и стили живут внутри `init`/`App`, а не в `index`.
  - `src/index` открывает сокет (`io()`), вызывает `init`, монтирует результат в `#chat`.
  - Dev-сервер Vite проксирует `/api` и `/socket.io` на `localhost:5001`.
  - `make build` — сборка; `make start` — `npx start-server -s ./dist` (отдаёт статику и API на 5001).
  - Деплой на Render (бесплатный тариф), ссылка на приложение — в README.
- **Роутинг (step=3).**
  - Маршруты `/` и `/login`; любой другой путь — страница 404.
  - На `/login` — форма входа (имя пользователя, пароль, кнопка отправки) на `useForm` из `@mantine/form`. Отправку на этом шаге не реализовывать.
